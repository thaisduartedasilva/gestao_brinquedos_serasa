Na Atividade de Recuperação — CRUD PHP: Sistema de Gestão de Brinquedos foi realizado um CRUD PHP com as funcionalidades de cadastro, edição, exclusão e listagem de um sistema de gestão de brinquedos, também fazendo uso de Prepared Statements para a garantia da segurança do sistema. Cada brinquedo possui as informações de ID, nome, categoria, faixa etária, preço e quantidade em estoque, para a sua identificação e organização no estoque da loja. O sistema também contou com todas as validações necessárias dos dados recebidos, e a organização adequada das pastas dos arquivos PHP de acordo com as boas práticas. A interface visual não é muito complexa mas permite ao usuário visualizar tudo com clareza e realizar as operações necessárias.
